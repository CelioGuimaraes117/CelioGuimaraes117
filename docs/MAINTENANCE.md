# Maintenance

## Edit the text

Edit `README.md` and `README.pt-BR.md` together, then run:

```sh
python3 -I scripts/validate_profile.py --links
```

The same checks run on every push (`.github/workflows/validate-profile.yml`).

## Metrics and images

Files under `assets/` and `data/` are generated by the private `celio-engineering-activity`
repository. Do not edit them by hand — the next run would overwrite them. To refresh manually, run that
repository's `metrics` workflow (`workflow_dispatch`).

## Add or change a project in *Selected work*

Only projects that are public, or whose owner approved a description, may be listed. Never include
client names, screenshots, internal URLs, branch names or PR titles. The validator blocks a list of
known confidential names (stored as hashes).

## Pinned repositories

GitHub has no API to set pinned repositories. Update them at
<https://github.com/CelioGuimaraes117> → *Customize your pins*.

## Rollback

Every change is a normal commit: `git revert <sha>` and push. To hide the profile README entirely,
rename this repository (the profile only renders for a repository named exactly like the account).
